# Android 4.0.3（V42）滚动修复

首页、教务、服务和我的共用 Compose 内的 WebView。新增 `ShellWebView`，在触摸按下时请求父容器不要拦截当前事件序列；抬起或取消后释放请求。首次创建和渲染进程崩溃后重建均使用此类型，页面内部滚动区域也沿用 WebView 的原生触摸处理。

版本号使用 42，避免与已经存在的本地 V41 测试包冲突。包名和发布签名沿用原版本。

验证范围：

- Android API 26、35 的 Robolectric 回归测试：按下、移动、抬起、取消、重新挂载、脱离父容器后的取消。换回普通 WebView 时断言失败。
- Android 15 模拟器：在首页、教务、服务和“我的”入口对应页面临时注入长内容，向上滑动后滚动位置超过 500 CSS px，反向滑动返回顶部附近；嵌套滚动区域可滚动。未登录时“我的”进入登录页，因此不代表已登录个人中心验收。
- Android 桥接测试；正式 APK 以精确提交的 GitHub Actions 制品为来源，签名及上传后的哈希另由发布门禁验证。

模拟器上的旧版基础滚动未稳定复现用户设备故障；此次覆盖的是 WebView 与原生父容器争用触摸事件的边界。真实设备及登录后的教务、个人中心仍需安装新版验收，不能用模拟器结果替代。
