# 账号删除、iOS 支付隐藏与社区隐私改造

本次改造覆盖源代码和数据库迁移；上线必须使用本次精确提交的 GitHub Linux 制品。没有执行生产部署、真实用户注销或 App Store 提交。

## 用户入口

- “我的 → 账号与隐私”（`/profile/privacy`）：查看和撤回 AI 同意、管理屏蔽列表、永久删除账户、凭回执查询清理进度。查询页允许退出登录后访问。
- 删除要求勾选范围说明、输入“删除我的账户”并确认不可恢复。浏览器先生成并保存随机回执再提交，避免服务器已受理而网络断开导致无法查询。
- 用户主页、帖子、回复和站内私聊提供屏蔽；匿名目标由后端解析真实账号，返回列表只含不透明屏蔽编号和显示标签。举报支持用户资料，并保留帖子、回复和私信举报。
- 公开资料变更进入人工队列，审核通过前不覆盖公开资料。“管理后台 → 举报处理”包含资料队列、超 24 小时提示、通过、驳回及清除违规资料。处理原因通过站内通知反馈。
- `/community-rules.html`、`/ai-privacy.html`、`/privacy.html` 为无需登录的静态规则页面。

## 删除过程与保留边界

`AccountDeletionJob` 保存持久化任务。提交事务将用户置为 `deleting`、撤销 OAuth 和小组件凭证、记录教务授权不可逆摘要；认证层即时拒绝旧账户。后台每 15 秒扫描任务，按数据库清理、会话/源存储、腾讯 CDN 刷新回执、VoiceHub 确认、缓存失效的顺序处理。外部步骤失败进入 `retry`，有指数退避；10 分钟失联的执行可重新领取。

数据库清理包括账号资料、绑定与关联日志、认证申请、站内教务关联、私聊双方消息、AI 对话和审核记录、问卷/文件收集任务及提交、失物信息等。帖子和回复清空并隐藏。用户行去标识化为不可登录、不可恢复的数字关联外壳；必要交易对账记录保留，移除留言、联系方式及非必要原始载荷。后续学校 SSO 会创建新的本站账号，不恢复旧账号。

文件仅从上传归属记录、本人头像和本站生图完成记录收集，不能根据用户粘贴的 URL 猜测所有权。引用既有论坛媒体不会改写其上传者。删除源存储后，对配置的腾讯 CDN 公网域名提交 URL 刷新并要求状态 `done`；缺少权限或未确认完成继续重试。若将来启用其他 CDN 作为公开交付源，必须先补充对应清理适配和验收。

VoiceHub 内部清理接口只接受能向主站回查成功的随机回执。清理影子用户资料、令牌、日志、通知、投票等，清空本人评论；保留不可登录的数字映射，阻止正在执行的旧会话重新建立身份。歌曲目录及既有排期保留去标识化的关联。此项不声称已经扩展了 VoiceHub 评论的举报/屏蔽系统；本次新增屏蔽覆盖主站论坛与站内私聊。

浏览器会清除记住的学校凭据、教务和社区缓存；iOS 桥清除当前设备小组件端点与缓存，并刷新时间线。其他离线设备、用户自行下载的副本、第三方模型历史副本、基础设施日志和备份不等于即时在线删除。删除回执页不返回姓名、学号、邮箱或清理载荷。

## AI 共享约束

当前声明按实际使用的模型服务及备用服务生成版本，包含运营方、域名、政策链接、留存说明、处理目的和数据范围。公开接口不返回 API 密钥。直接官方服务有保守的默认说明；只有明确为本机 Ollama 的端点自动标记为本地服务，localhost 代理不作该推断。

自定义代理必须在 AI 服务配置中填写 `privacyOperator`、`privacyPolicyUrl`、`privacyRetention`，说明代理和上游实际接收方。无法核实的运营方不能凭接口兼容性冒充 OpenAI。缺少说明时阻止用户数据发送；既有用户不会被批量视作已同意。修改接收方配置或声明版本后需要重新明确确认。

前端首次相关操作展示可拒绝的确认窗；后端内容提交以及文本、媒体、生图等实际调用再次校验。撤回后暂停新的依赖 AI 操作，登录、课表和浏览继续可用；公开资料提供人工审核路径。已在传输中的请求无法因撤回追溯取消。没有承诺第三方零留存或自动删除其历史副本。

## iOS 范围

所有 iOS 用户统一隐藏赞助、支付、VIP 兑换入口；路由访问回到个人页。原生 WKWebView 与外部打开桥阻断本站支付/兑换路径及已知支付跳转，服务端拒绝带 iOS 客户端标识的对应接口。已拥有的权益显示不等于提供购买入口。本次未改 Android、鸿蒙或桌面原生安装代码，也没有停用其他渠道后端支付回调。

## 迁移和上线验收

迁移文件为 `server/prisma/migrations/20260907090000_account_privacy_and_safety/migration.sql`，已接入 `npm run db:migrate`，支持重复执行。服务端、Web 和 VoiceHub 必须使用同一个已验证制品更新，先完成迁移再接收新请求。保留现有加密密钥；删除队列载荷依赖它解密。

上线前由运营方完成：

1. 核实实际 AI 代理、上游、数据所在地和留存说明，在管理界面填写；没有这些事实时功能保持不发送用户数据。
2. 确认腾讯 CDN 凭据具备 `PurgeUrlsCache` 和 `DescribePurgeTasks` 权限，并检查 URL 参数及图片变体的缓存刷新策略。确认所有已启用的公开存储/CDN 均纳入清理范围。
3. 用专用测试账号验证跨系统删除、旧设备小组件失效、真实源存储与 CDN 回读、后台失败重试；不得用真实用户验证删除。运维可只查询任务 `id/status/phase/lastError/attempts/nextAttemptAt`，不要输出加密载荷或原始回执。
4. 确定日志和备份的实际保留周期并对外准确说明。保留独立可恢复的删除/撤销清单；恢复旧备份前重放清理与凭据撤销，不能重新开放已删除身份。
5. 落实举报和资料审核的 24 小时首次查看目标，安排邮箱及人工复核值守。代码中的提示不能替代值守。
6. 在 macOS/Xcode 生成签名 iOS 构建，用真机验收支付隐藏、声明弹窗、删除确认和小组件清除；同步 App Store 隐私答案、审核说明及可用测试账号。源码编译不能代替这一步。
